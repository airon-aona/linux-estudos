# Atalhos do Terminal

Principais atalhos de teclados para usar no terminal Linux.

## Navegação e Edição de linha

- Tab - Completa comandos, nomes de arquivos e diretórios, pressionar duas vezes mostra as opções.
- CTRL + A - Move o cursor para o inicio da linha.
- CTRL + E - Move o cursor para o final da linha.
- CTRL + B ou Seta Esquerda - Move o cursor um caractere para trás.
- CTRL + F ou Seta Direita - Move o cursor um caractere para frente.
- ALT + B ou CTRL Seta Esquerda - Move o cursor uma palavra para trás.
- ALT + F ou CTRL Seta Direita - Move o cursor uma palavra para frente.

## Apagar Texto

- CTRL + U - Apaga tudo desde o cursor até o inicio da linha.
- CRTL + K - Apaga tudo desde o cursor até o final da linha.
- CTRL + W - Apaga a palavra que esta logo antes do cursor.
- CTRL + Y - Restaura o ultimo texto apagado com os comando anteriores.

## Controle de Processo

- CTRL + P ou Seta para Cima - Mostra o comando anterior do histórico.
- CTRL + N ou Seta para Baixo - Mostra o próximo comando do histórico.
- CTRL + R - Faz busca recursiva no histórico de comandos, digite partes do comando para encontrar.
- CTRL + C - Interrompe (Mata) o programa ou comando que esta rodando no momento.
- CTRL + Z - Envia o processo para segundo plano, pode conseguir isso antes de executar o programa usando a opção &.
- CTRL + D - Encerra a sessão do terminal, equivalente ao comando `exit`.
- CTRL + L - Limpa o terminal, equivalente ao comando `clear`.

## Copiar e Colar

- CTRL + SHIFT + C - Copia o texto selecionado.
- CTRL + SHIFT + V - Cola o texto da área de transferência.
